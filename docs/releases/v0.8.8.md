# HoldMySession 0.8.8

The same program as 0.8.7, with a new version number, so the in-app update from 0.8.7 can be tried.

Nothing else changed. To try it: install 0.8.7, start the app yourself, then in Settings, Updates press Check for updates and Update now. It should download, swap the files, start again as 0.8.8, and write the steps to `%USERPROFILE%\.holdmysession\updates\apply-update.log`.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
