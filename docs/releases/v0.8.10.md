# HoldMySession 0.8.10

After an in-app update the app now starts again by itself.

- **Why it did not come back.** The update step runs the app's own program in a plain-Node mode (`ELECTRON_RUN_AS_NODE`). The program it started again afterwards inherited that setting, so it ran as plain Node, found nothing to do, and exited at once. The app is now started with those settings taken out, from its own folder, and if it cannot be started the reason is written to `%USERPROFILE%\.holdmysession\updates\apply-update.log`.
- **More patience for the old program to let go.** In 0.8.9 the swap got through, but only after about 14 seconds of retries while something still had `HoldMySession.exe` open. It now keeps trying for up to two minutes before it gives up and puts the old version back.
- **The log says when it could not look.** If the update step cannot list the programs running from the install folder, `apply-update.log` now says so, instead of saying "nothing found".

**Updating to 0.8.10.** From 0.8.7 and later the update uses the step that comes with the new version, so Update now should swap the files and start the app again.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
