# HoldMySession 0.9.1

Fixes "Failed to load projects: Forbidden" when the dashboard is opened from a browser.

- **The fix.** The framework update in the last release added a check that every request comes from the page it was served to. HoldMySession compared it with `localhost`, so a page opened at any other address, such as the computer's network address, its name, or a Tailscale name, was refused, and the Map, Stats and Sessions failed to load with "Forbidden". It now compares with the address you actually opened. Requests from other sites are still refused.
- The app window, which always opens `localhost`, was not affected.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
