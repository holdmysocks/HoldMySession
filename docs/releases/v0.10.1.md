# HoldMySession 0.10.1

A session waiting on a background task no longer looks done.

- **Fixed.** A session that was waiting on a long command running in the background showed as Done or Idle. Claude Code now keeps the output of those tasks in a different folder than the one HoldMySession looked in, so they were never seen. They are now.
- **It says what it is waiting on.** The Sessions list shows "Waiting on 1 background task", or "Waiting on 2 agents and 1 background task" when agents are running too, and the Map's cards, tree and detail panel say the same. It reads "Working with …" while the session is still writing, and the status shows Running rather than Done.

A task whose output stays silent for more than 10 minutes still stops counting. Claude Code does not record whether a task is alive, so that cannot be told apart from an abandoned one.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
