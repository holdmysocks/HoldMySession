# HoldMySession 0.6.0

The first desktop release.

## Desktop app
- Runs as a window with a tray icon, and keeps running when the window is closed. The same app is still at http://localhost:3000.
- Windows zip: unzip it anywhere and run `HoldMySession.exe`. It is not signed, so Windows SmartScreen will warn on first run: choose **More info**, then **Run anyway**.
- The app is built so it can also be built for Mac (`node scripts/package.mjs darwin arm64 x64`). A Mac download is not published yet.

## New
- **Linked machines:** one machine is the master and others send it their history. The master shows each node's live sessions, session detail and map, and a Machine filter on every page.
- **Claude Code hooks** are set up from Settings: Needs you notifications, and starting HoldMySession when Claude Code starts. Only those entries are added or removed.
- **History database:** your usage is kept in `~/.holdmysession`, with dated prices, your subscription, automatic scans, and backup and restore.
- 12-hour or 24-hour clock, the Max and Ultra plan names, and the version and update check in the sidebar.

## Needs
Nothing to install. To run from source instead, Node.js 22.13 or newer.

Checksums are in `SHA256SUMS.txt`.
