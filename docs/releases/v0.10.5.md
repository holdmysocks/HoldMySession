# HoldMySession 0.10.5

Stats now shows how long you actually worked, and its "vs before" comparison stops showing nonsense.

- **"Time with Claude" is now active time.** It used to add up how long each session was open, from its first message to its last, including every pause and every session running in parallel, which gave absurd totals (thousands of hours). It now counts the gaps between messages of ten minutes or less; a longer pause counts as time away. Time is counted on the day it happened.
- **Sessions whose transcripts are gone** can't be measured exactly, so their time is estimated at about 45 seconds a message, never more than the session was open.
- **"vs before" only appears when there is something to compare against**, and a big jump is shown as a multiple (for example 12×) instead of +1200%.
- **The first scan after updating reads every transcript once** to work out the new numbers, as in 0.10.4.
- **Update every linked machine together.** The history database changed, and linked machines on different versions will not sync until they match.

Checksums are in `SHA256SUMS.txt`.
