# HoldMySession 0.8.12

A session is not done while its agents are still working.

- **No more false "done".** A session whose own transcript has gone quiet but whose subagents are still running now stays RUNNING, on the Sessions page, the Map and the counts. It only becomes done when every agent has finished.
- **See what it is waiting for.** The Sessions list says "Working with N agents", or "Waiting on N agents" once the session itself has been quiet for two minutes. The Map shows the same on session cards and in the tree, and the detail panel spells it out.
- **Lines that move.** On the Map, the line from a session to an agent that is working flows toward the agent. It stays still if you have reduced motion turned on.
- **Up to date and secure.** Every library the app builds on is on its current release, which clears all the known security advisories (the web app had 43, three of them critical). The desktop app moves to Electron 45.2.1.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
