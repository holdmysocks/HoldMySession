# HoldMySession 0.7.0

Settings is split into tabs, there is a Projects tab, the map shows every machine, and the desktop app can update itself.

- **Settings tabs.** General, Projects, Data, Machines, Claude Code, Plan and pricing, and Updates. A tab can be linked to, such as `/settings?tab=projects`.
- **Projects tab.**
  - Scratch sessions can be grouped as **Unlinked Sessions**, listed folder by folder, or hidden from lists. A second switch names them by their session name.
  - Any project found on this computer, or on a linked machine (grouped by machine), can be hidden from lists and dropdowns.
  - Hiding only changes lists and dropdowns. A hidden project's usage is still counted in every total, chart and cost.
- **Sessions** now has the same Unlinked Sessions entry as Stats, and follows the Projects settings.
- **Map, all machines.** On a master, the project dropdown now lists the projects of every connected node, grouped by machine, instead of only this computer's.
- **Updates.** Settings, Updates has **Check for updates**, **Update now** (downloads, checks the file against `SHA256SUMS.txt`, installs and restarts), and **Install updates automatically** (downloads in the background and installs when the app next closes). Updating itself needs the desktop app installed in a folder you can write to, and a release that includes `SHA256SUMS.txt`.

Checksums are in `SHA256SUMS.txt`. The first version with this updater is 0.7.0, so updating *to* 0.7.0 is still a manual unzip.
