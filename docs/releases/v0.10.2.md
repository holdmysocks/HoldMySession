# HoldMySession 0.10.2

HoldMySession now uses far less memory while it sits in the tray.

- **Closing the window really closes it.** The page and its process, about 85 MB, are freed, instead of only being hidden. The tray icon opens a new window.
- **Smaller idle footprint.** Hardware graphics are off (the dashboard does not need them), and the app only checks which sessions need you while Claude Code is in use, so it does nothing the rest of the time. The history scan no longer re-reads every transcript when none changed.
- **Quits when Claude Code is not in use.** After 10 minutes, 30 minutes (the default), 1 hour or 2 hours of no Claude Code activity, HoldMySession quits, and the Claude Code start hook starts it again with your next session or message. It never quits while its window is open, while a session needs you, on a computer linked to another, or without the start hook. Settings, General. If you turned the start hook on before, switch it off and on once so it also fires on each message.
- **It stays out of your way.** When the Claude Code start hook starts the app, it goes straight to the tray with no window. A new switch in Settings, General, "Open the window when Claude Code starts it", turns that around.
- **Faster scans.** A change in 0.10.1 made every scan about four times slower. Fixed.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
