# HoldMySession 0.9.0

Your usage limits, right in the header.

- **A limits chip.** The header shows how much of your subscription limit is used and how long until it resets. It turns yellow from 75% and red from 90%. Click it for the meters, what your current pace means ("limit reached around 9:52 pm at this pace"), and a drawer of which sessions used the most.
- **The real numbers.** In Settings, Claude Code, switch on Show my real limits. Claude Code reports your limits only to its status line, so this makes HoldMySession the status line. If you already have one, it is saved, keeps running and looks the same, and comes back exactly when you switch this off. A copy of Claude's settings file is saved first. Until it is on, the chip shows a labelled estimate counted from your transcripts.
- **No 5-hour limit, no 5-hour meter.** Plans such as Ultra only have a weekly limit. The 5-hour meter appears only once Claude Code has reported a 5-hour window, so on those plans you only see the weekly one, estimates included. Settings can also always show or never show it.
- **Alerts (desktop app).** A notification as a limit passes 75% and 90%, and when a limit you had run up resets. The tray tooltip shows the numbers.
- **Everything updated.** All the libraries the app builds on are on their current releases, which clears every known security advisory (the web app had 43). The desktop app moves to Electron 45.2.1.
- **Quieter repository.** The GitHub workflows and dependency bot that came with the fork are gone.

Update every linked machine. Linked machines each keep their own limit numbers for now.

Checksums are in `SHA256SUMS.txt`.
