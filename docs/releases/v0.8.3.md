# HoldMySession 0.8.3

The desktop app is now a few dozen files, not nineteen thousand.

- **One archive instead of 19,000 files.** The program used to ship every file of every library it uses, which made unzipping, virus scanning and updating slow. They are now packed into one file, `resources\app.asar`. The download is about the same size, and the app behaves the same.
- **Updating from the app** works as before. The update step also swaps the new archive in, and puts the old one back if the swap fails.
- **Updating by hand:** if you unzip over an older install, delete its `resources\app` folder first. Otherwise the old files can be loaded instead of the archive. Unzipping into a new folder avoids this.

Update every linked machine, as with 0.8.2.

Checksums are in `SHA256SUMS.txt`.
