# HoldMySession 0.8.2

A fix for the window popping up whenever Claude Code starts a new chat.

- **The start hook no longer opens, raises or focuses the window.** If HoldMySession is not running, the hook starts it in the tray with no window. If it is running, even minimised to the taskbar or hidden, the hook does nothing.
- **Why it happened.** The hook checked whether the app was running on `127.0.0.1` only, but the app listens on `localhost`, which on Windows can be the IPv6 address. The check missed a running app, the hook started a second copy, and that copy told the first one to show its window. The check now tries both addresses, gives a busy app a moment to answer, and a copy started in the background can no longer make a running one show its window.
- Starting the program by hand, or clicking the tray icon, still shows the window.

Update every linked machine to 0.8.2, as with 0.8.1.

Checksums are in `SHA256SUMS.txt`.
