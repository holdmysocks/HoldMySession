# HoldMySession 0.8.4

Updating from inside the app now works when the app was started by Claude Code.

- **Update now / automatic updates.** The app starts a small PowerShell step to swap in the new version, and it asked for it by name only (`powershell.exe`). When the app had been started by a Claude Code hook, its search path could be without Windows PowerShell, so the step never started and the app quit with nothing said. It is now started by its full path.
- **If the update step cannot start, the app stays open** and Settings, Updates says why. Before, it quit anyway. A note is also kept for the next start.
- **A step-by-step log of the swap** is kept in `%USERPROFILE%\.holdmysession\updates\apply-update.log`, so a swap that goes wrong can be read afterwards.
- **The new version starts as soon as the files are in place**, before the old copy is cleared away.
- **A dot on the Updates tab** in Settings when a newer version is out, matching the one on the gear.

**Updating to 0.8.4.** The update step is run by the version you are updating *from*, so updating 0.8.3 to 0.8.4 from the app still uses the old way of starting PowerShell. If the app was started by Claude Code, that can fail as it did before. Start HoldMySession yourself first (from the Start menu, the folder, or the tray), then press Update now. Or unzip by hand: quit the app, move the old folder aside, and unzip the new one in its place. From 0.8.4 on, updates work from the app however it was started.

Checksums are in `SHA256SUMS.txt`.
