# HoldMySession 0.8.5

Updating from inside the app, made to work without PowerShell.

- **A new way to swap the files.** After Update now, the app used to start a hidden PowerShell script to put the new version in place. On some machines that never ran: the app closed, nothing came back and the old version stayed. The new version's own program now does the swap, in a quiet Node mode, from the folder the update was unpacked into. It needs no PowerShell, no execution policy and no hidden window. If it cannot start, PowerShell (by its full path) is tried next.
- **If the update cannot be started the app stays open** and Settings, Updates says why, with a note kept for the next start.
- **A step-by-step log** of every swap is written to `%USERPROFILE%\.holdmysession\updates\apply-update.log`.
- **Left-over update folders** from a swap that could not clear itself are removed when the app next starts.
- The old version is put back, and the app started again, if the swap fails part-way.

**Updating to 0.8.5.** The swap step is run by the version you update *from*, so updating 0.8.4 or older from the app still uses the old way and can fail the same way. If it does, unzip by hand: quit the app, move the old folder aside, and unzip the new one in its place. From 0.8.5 on, updates use the new step.

Checksums are in `SHA256SUMS.txt`.
