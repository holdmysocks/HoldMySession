# HoldMySession 0.10.0

HoldMySession now runs on a Mac with Apple Silicon.

- **A Mac app.** Open the `.dmg`, drag HoldMySession onto Applications, and run `xattr -dr com.apple.quarantine /Applications/HoldMySession.app` once (or choose Open Anyway in System Settings, Privacy and Security). It is signed ad hoc, which Apple Silicon needs to run it, but not notarized, so macOS asks once. It lives in the menu bar, and its Dock icon shows only while its window is open. It updates itself from Settings, like the Windows one.
- **Quiet hooks on a Mac.** Claude Code's hook and the status line run the app as plain Node, so no Dock icon flashes each time Claude Code calls them.
- **Copy works over plain http.** The pairing code and address Copy buttons did nothing when a master was opened at its network address from another computer, because browsers only allow the clipboard on secure pages, yet they still said "Copied". They now copy there too, and only say Copied when it worked. If a browser still refuses, the pairing code is shown to select by hand.

The Windows app is unchanged apart from the copy fix. Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
