# HoldMySession 0.8.11

A bigger map, and a glowing circle instead of a glowing box on the Sessions list.

- **The map uses the whole screen.** On a wide or ultrawide monitor it now runs edge to edge and is taller, so there is room to see a big project and zoom in. The page's title and buttons stay in a readable column.
- **Full screen.** A new button on the Map makes it fill the window. Close it with the button or Esc.
- **Sessions list.** A running, waiting or finished session shows a small glowing circle beside its status word, instead of the whole row glowing. Several running sessions no longer pile glowing boxes on each other. A session that needs you keeps a plain amber outline.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
