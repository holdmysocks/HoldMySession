# HoldMySession 0.10.3

Quit when idle now works on linked machines, with a switch for every machine.

- **Nodes can quit.** A node quits after Claude Code has gone unused (10 minutes to 2 hours, 30 by default), and the Claude Code start hook starts it again. Before it quits it sends its latest sessions to its master, and it stays if something starts while it is sending. The master shows it as offline until it starts again.
- **A master never quits**, so its nodes can always reach it.
- **A switch for every machine, in one place.** Settings, Machines, Linked machines shows the quit-when-idle switch and time for each machine. On a master, changing a node's switch keeps the choice, and the node takes it the next time it syncs, even if it has quit by then ("Applies when it next connects" until it has). A change made on the node afterwards wins over an older one at the master, and the other way round. A node shows up here once it has updated.
- On a machine's own Settings, General, the same switch is there, and is disabled on a master.

Update every linked machine.

Checksums are in `SHA256SUMS.txt`.
