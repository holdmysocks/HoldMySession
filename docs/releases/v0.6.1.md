# HoldMySession 0.6.1

Fixes for the desktop app, and easier linking.

- **Start with Windows** now shows its tick in the tray menu, and there is a matching switch in Settings, under Desktop app.
- **Linking is one paste.** A master shows a pairing code and its addresses. A node pastes the code and tries every address, so it works on the local network and over a tailnet.
- **The firewall is handled for you.** Turning on Listen on the network asks Windows for the permission, limited to your network and tailnet, and offers Restart now. If you decline, the Settings card says so and has a button to ask again.
- A node that cannot connect says why, such as the master not listening, a firewall, or a name that was not found.

Checksums are in `SHA256SUMS.txt`.
